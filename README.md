# Solver Core V2 là một tiện ích pick đáp án tool LMS DUT & Azota 
# Extension sử dụng API của Gemini, OpenAI để tự động pick đáp án và hoàn thành bài tập (Vibe coding)
## Lưu ý: Khuyên dùng Gemini với mô hình gemini-3.6-flash vì đc nhiều RPM Token
# Hướng dẫn sử dụng:
  ## B1: Tải về và lưu với thư mục solver-core
  ## B2: Vào Manage Extensions trên Chrome hoặc Microsoft Edge, kích hoạt chế độ nhà phát triển (Developer Mode)
  ## B3: Ở mục Load unpacked, nhấn vào rồi chọn mục solver-core đã lưu.
  ## B4: Lấy API của Gemini thì vào trình duyệt tìm kiếm Google AI Studio và đăng nhập như bình thường. Tiếp theo vào mục Dashboard ở thanh Menu và ở dòng Dự án (Project) chọn API keys và Tạo (Key phải giữ bảo mật không được chia sẻ), lấy xong mọi người vào extension Solver Core V2 rồi làm theo dòng sau: Google Gemini -> [Key vừa tạo] -> Dán model này vào (gemini-3.1-flash-lite) -> Chỉnh thời gian next cần thiết.
  ## B5: Nhấn TEST KẾT NỐI, hoạt động lưu cấu hình lại
# Xin chú trọng nếu tool không chạy thì hãy vào Google AI Studio để check xem đã vượt quá giới hạn lượt truy cập thì đổi model ở Rate limit (nhập giống định dạng model ở bước 4)
